Jovens de Web - Vocação

Conheça algumas áreas da tecnologia!

HTML

O HTML (HyperText Markup Language ou Linguagem de Marcação de Hipertexto) é a linguagem padrão usada para criar e estruturar o conteúdo de páginas na World Wide Web.

CSS

O CSS (Cascading Style Sheets ou Folhas de Estilo em Cascata) é uma linguagem usada para definir a apresentação, o design, as cores e o layout visual de páginas web escritas em HTML.

JavaScript

JavaScript é uma linguagem de programação interpretada, de alto nível e com tipagem dinâmica, usada para criar páginas e aplicações web interativas.
